# Project K

Project K is an experimental operating system and kernel built from the ground up for learning and exploration.

## K v0.1

Initial objective:

- Boot through GRUB
- Enter the kernel
- Execute C code
- Write directly to VGA text memory
- Run safely inside QEMU

## Architecture

Initial bootstrap: x86 32-bit Multiboot

Long-term target: x86-64

## Development Environment

- Ubuntu 24.04
- WSL2
- GCC
- NASM
- GNU Binutils
- Make
- GRUB
- QEMU
- GDB
- Git
